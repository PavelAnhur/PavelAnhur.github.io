LLM Test Harness

github.com/PavelAnhur/llm-test-harness

A test harness for non-deterministic LLM outputs, built over five weeks and documented week-by-week. Property-based assertions replace exact-match checks; pass-rate thresholds gate multi-run suites; adversarial input tests cover prompt injection, role confusion, and payload splitting. Includes a rubric-based LLM-as-a-judge calibrated against 25 hand-labeled examples, and a real RAG retriever — Qdrant vector database, nomic-embed-text embeddings via Ollama, and a deterministic chunker — with faithfulness, relevance, context precision, and context recall metrics. Streaming tests cover token delivery, time-to-first-token, and mid-stream disconnect. Every finding and calibration round is written up, including the ones where the judge disagreed with the human label.

Live Allure report: pavelanhur.github.io/llm-test-harness
